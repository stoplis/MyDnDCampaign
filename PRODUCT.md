# Product

## Register

product

## Platform

web

## Users

Primary: Stephen, the DM, using the DM Screen live at the table to run the session — party HP/AC, chapter notes, bestiary, encounters, and the combat tracker all need to be found fast without breaking flow. Secondary: Stephen's family, the players, using the simpler tools (Campaign Journal, Spell Book, Fast Crafting, Spider Merchant) on their own devices to reference their characters and unlock story content as the DM reveals it — with no explanation needed from Stephen.

## Product Purpose

A set of browser-based tools that support running a home D&D 5e campaign end to end: fast, reliable data access for the DM during live play, and lightweight self-serve references for the family between and during sessions — all without ever surfacing the campaign's underlying twist or spoilers to the players who use it.

## Positioning

Built exactly for this table. The party data, chapter notes, and progressive spoiler-safe reveals are baked in for this specific campaign — not a generic, reusable reference tool a stranger could pick up.

## Brand Personality

Editorial and literary. Serif typography, restrained ink tones, hairline rules — it should read like a well-typeset book or journal, not a game HUD or dashboard. Calm and legible under table lighting, not flashy. The DM Screen is already close to this in structure (near-white surface, true-black ink, serif display type); the accent color is the one piece currently off-brand — it should be **gold**, not the terracotta/salmon currently applied throughout, and gold should read as the toolkit's one primary color, used deliberately rather than everywhere.

## Anti-references

Generic SaaS dashboards — card grids, blue gradients, corporate-tool chrome. Bright mobile-game fantasy UI — saturated gem-tone buttons, glossy icons, freemium-RPG look. Gritty grimdark — excess darkness, blood-and-grit styling, too heavy for a family table. Cartoonish or kids'-app styling — overly playful, rounded, illustrated-for-children.

## Design Principles

The DM Screen is the north star: it's the primary use of the toolkit, and every other tool (Campaign Journal, Spell Book, Fast Crafting, Spider Merchant, the landing page) inherits its editorial system rather than developing its own look. Gold is the one primary accent, reserved for true accents and selected state — not a wash applied everywhere. Never break the DM's flow: legibility and speed at the table outrank decoration. Family-facing tools stay simple and self-explanatory, with no DM jargon or unlabeled icons. Never leak campaign spoilers — the Pinocchio inspiration and any plot twists — into player-facing surfaces.

## Accessibility & Inclusion

Standard good practice: solid WCAG AA contrast for body text, readable type sizes, comfortable for a family table under variable lighting. No stricter WCAG level or specific accommodation was flagged.
